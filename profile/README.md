# Supabase

**The Postgres development platform.** Supabase gives you a dedicated Postgres database to build web, mobile, and AI applications, with Auth, Storage, Realtime, Edge Functions, and Vector search built in.

[Start your project](https://supabase.com/dashboard) · [Docs](https://supabase.com/docs) · [Blog](https://supabase.com/blog) · [Discord](https://discord.supabase.com) · [X](https://x.com/supabase)

## Start here

- [supabase/supabase](https://github.com/supabase/supabase): Studio, docs, and the home for issues and discussions.
- [supabase/cli](https://github.com/supabase/cli): Run Supabase locally, manage migrations, and deploy Edge Functions.
- [supabase/mcp](https://github.com/supabase/mcp): Connect Supabase to your AI assistants.
